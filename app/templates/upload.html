Upload Financial Data

Accepted formats: PDF, Excel (.xlsx, .xls), CSV. Maximum file size: 16MB

Upload Instructions

Excel/CSV Format

For Excel or CSV files containing financial metrics, use the following column headers (case-insensitive):

Column Name Description Required
Year Year (e.g., 2024) Yes
Quarter Quarter number (1, 2, 3, or 4) Yes
Revenue Total revenue for the quarter No
ARR Annual Recurring Revenue No
cARR Committed Annual Recurring Revenue No
LARR Linear Annual Recurring Revenue No
Gross Margin Gross margin as decimal (0.7 = 70%) No
Burn Rate Monthly burn rate No
Cash Balance Current cash balance No
Customer Count Total number of customers No
Notes Additional notes or comments No

Example CSV

Year,Quarter,Revenue,ARR,cARR,LARR,Gross Margin,Burn Rate,Cash Balance,Customer Count
2024,1,1500000,6000000,7000000,6500000,0.72,200000,5000000,150
2024,2,1800000,7200000,8000000,7600000,0.75,180000,5200000,175

PDF Format

For PDF quarterly decks, the system will attempt to automatically extract financial metrics using pattern matching. For best results:

  • Include clear labels for metrics (e.g., "Revenue: $1.5M", "ARR: $6M")
  • Specify the quarter (e.g., "Q1 2024")
  • Use consistent formatting

Note: PDF parsing is experimental. For accurate data import, use Excel or CSV format.
