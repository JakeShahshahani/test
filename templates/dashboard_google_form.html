Google Form Integration Setup

Set up a Google Form for portfolio companies to submit their quarterly metrics

📝 How It Works

1. Create a Google Form with the required fields
2. Configure the form to send responses to the webhook URL below
3. Portfolio companies fill out the form each quarter
4. Data automatically updates all dashboards and charts

Setup Instructions

  1. Create a new Google Form
  2. Add all required fields (exact names as shown above)
  3. Add optional fields as needed
  4. For "Company Name", create a dropdown with all portfolio companies
  5. Install the "Form Publisher" or "Form to Webhook" add-on
  6. Configure the add-on to POST form responses to the webhook URL above
  7. Test the form by submitting sample data
  8. Check the dashboards to verify data appears correctly
